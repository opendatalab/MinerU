## 开始使用

`mineru` 是面向交互和 Agent 工作流的文档库 CLI；无状态批处理、V1 API Server、Gradio、模型管理和多服务 Router 使用 `mineru-kit`。

建议按照上述顺序阅读文档，这样可以帮助您更好地理解和使用项目功能。

如果您在使用过程中遇到问题，请查看 [FAQ](../faq/index.md)
