# 历史文档档案

这里保存过去的设计、迁移、评审和实验记录，不作为当前产品说明。历史版本、测试数字和失败结果保留原意。
当前行为见 [用户文档](../zh/index.md) 和 [开发文档](../next/README.md)；后续工作集中在 [当前待办](../next/backlog.md)。

| 目录 | 内容 |
|---|---|
| plans、superpowers | 早期实现计划与设计；包含外部 my-pdf 项目的历史方案，不属于当前 MinerU 实施计划 |
| design | 被替代的 Telemetry 设计、早期路线图、任务拆分和差异评审 |
| migrations | DocGale/DocVortex 及 Transformers 迁移时的操作与依赖快照 |
| validation | 某次宿主集成、协议或 PDF 修复的验证记录 |
| performance | 按设备和日期记录的 ONNX/llama 实验；benchmarks 保存原始 JSON |
| reviews | 已完成的结构优化、PR 处理与配套证据 |
| middle-json | 旧结构盘点与迁移方案 |
| platforms、integrations | 旧平台及第三方教程快照，不代表当前兼容性 |
| testing | 历史手工验收方案，执行前须按当前接口更新 |
| attachments | 没有现行入口引用的历史 PDF/XMind 附件 |

未采纳的设计见相邻 proposals 目录。归档正文和附件目录不整体发布到 GitHub Pages；旧文档网址跳转到本仓库，旧数据下载网址保留原始字节。
