# Crossnote HTML styles

These files are unmodified compiled CSS resources bundled with Markdown Preview
Enhanced (MPE) 0.8.30, which declares Crossnote 0.9.31 as an exact dependency.
They are redistributed under the University of Illinois/NCSA Open Source
License in [LICENSE.md](./LICENSE.md).

The byte-for-byte source was the installed MPE 0.8.30 extension. Paths below
are relative to the extension installation root:

| Vendored file | MPE/Crossnote distribution path | SHA-256 |
| --- | --- | --- |
| `github-light.css` | `crossnote/styles/preview_theme/github-light.css` | `020bb992e41828c9ef14f687f2a71e99e2bf6f69e32de9d1ee1e292604f0d779` |
| `style-template.css` | `crossnote/styles/style-template.css` | `054061cb501481af702df4adf8d2c224d666b6fe78a84a1c3a362e6a92cfdcdf` |
| `github.css` | `crossnote/styles/prism_theme/github.css` | `885fa37a859ef386c471e7dee272e882d09c1c600b853b6f518daf40bbd1ba02` |

The upstream CSS artifacts are minified single-line files without a trailing
newline. Keep them byte-identical so the checksums remain useful.
